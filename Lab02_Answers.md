# Лабораторна робота № 2 — оператори та типи даних

**Варіант:** 4  
**Завдання:** № 10, 11 і 12

## Позначення

- sh(x) — гіперболічний синус, Math.sinh(x).
- ch(x) — гіперболічний косинус, Math.cosh(x).
- lg(x) — десятковий логарифм, Math.log10(x).
- ln(x) — натуральний логарифм, Math.log(x).
- arcsin(x) — обернена функція синуса, Math.asin(x), результат у радіанах.

## Завдання 10

Формула: y = a^b / sh(|b|) + 4 * ln(c) / ⁴√d.

Параметри: a = 1.27, b = 10.99, c = 2.73, d = 25.32.

Результат: y ≈ 1.791312522465.

## Завдання 11

Параметри: a = 0.478, b = -1.26, c = 2.68, d = 18.24.

Результат: y ≈ 10800873.662501.

## Завдання 12

Результат: y ≈ 2.968643704848.

## Контрольні питання

1. **Ключові та зарезервовані слова.** Ключові слова мають визначене значення в синтаксисі Java (class, if, return). Зарезервовані слова не можна використовувати як ідентифікатори, хоча деякі з них (const, goto) наразі не мають практичного призначення в мові.

2. **Примітивні типи.** boolean — логічні умови; byte — невеликі значення або байти даних; short — невеликі цілі числа; char — UTF-16 кодові одиниці; int — звичайні цілі числа; long — великі цілі числа; float і double — числа з рухомою комою (double точніший і є типовим вибором для дробових обчислень).

3. **Знакові та беззнакові типи.** Знаковий тип може зберігати від’ємні й додатні числа. У Java цілі типи byte, short, int, long знакові; char — беззнаковий 16-бітний тип зі значеннями від 0 до 65535. boolean зберігає true або false.

4. **Максимальні значення.** short: 32 767; char: 65 535; int: 2 147 483 647; long: 9 223 372 036 854 775 807.

5. **Діапазон byte.** Тип byte має 8 біт і подає знакові цілі числа в додатковому коді. Його діапазон: від −2⁷ до 2⁷−1, тобто від −128 до 127. Діапазон несиметричний, бо одне з 256 можливих значень використовується для нуля.

6. **Система числення.** Це спосіб запису чисел за основою та набором цифр. Позиція цифри задає степінь основи. Наприклад, 13₁₀ = 1101₂. Для перетворення десяткового цілого числа в двійкове його послідовно ділять на 2 і читають остачі у зворотному порядку; у Java також є метод Integer.toBinaryString(value).

7. **Додатковий код.** Це спосіб кодування знакових цілих чисел у двійковому вигляді. Щоб отримати від’ємне число з додатного, інвертують біти й додають 1. Такий код дає змогу виконувати додавання та віднімання єдиною схемою.

8. **Результат фрагмента з int.** Сума 2 000 000 000 + 2 000 000 000 перевищує максимальне значення int. Через переповнення 32-бітне значення обгортається, тому програма виведе -294967296. Для такого діапазону слід застосувати long.

9. **float і double.** float займає 32 біти й має приблизно 7 значущих десяткових цифр; double займає 64 біти й має приблизно 15–16. double точніший і займає більше пам’яті.

10. **Число з рухомою комою.** Це число, яке зберігається приблизно як знак × мантиса × основа у степені. Мантиса містить значущі цифри, а степінь задає масштаб. Такий формат може представляти дуже великі й дуже малі значення, але часто з округленням.

11. **Double.NaN.** Це спеціальне значення «не число» для невизначеного результату обчислення з рухомою комою, наприклад 0.0 / 0.0. Для перевірки використовують Double.isNaN(x).

12. **Порівняння Double.NaN == Double.NaN.** Результат — false: за правилами IEEE 754 значення NaN не дорівнює жодному значенню, навіть самому собі. Для перевірки треба використовувати Double.isNaN.

13. **Преінкремент і постінкремент.** ++i спершу збільшує i, а потім повертає нове значення; i++ спершу повертає старе, а тоді збільшує i. Наприклад, за i = 5, x = ++i дасть x = 6, i = 6, а x = i++ дасть x = 5, i = 6.

14. **Логічний і побітовий AND.** && працює з boolean і використовує коротке замикання: якщо ліва частина false, права не обчислюється. & для цілих чисел виконує побітове AND, а для boolean обчислює обидва операнди без короткого замикання.

15. **OR і XOR.** OR (| або короткозамкнений || для логічних значень) дає true, якщо істинний хоча б один операнд. XOR (^) дає true, коли операнди різні — істинний рівно один.

16. **Результат фрагмента програми.** У першому виразі true && false | false оператор | має вищий пріоритет за &&, тому значення дорівнює false; присвоювання a = false друкує false. У другому true && false || false спершу обчислюється &&, потім ||, отже значення також false; але в println виконується присвоювання b = true, тому друкується true.

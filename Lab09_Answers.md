## Завдання 4 — перетворення шістнадцяткового рядка на int

Метод hexStringToInt приймає рядок із числом у шістнадцятковій системі та повертає його значення типу int. Для перетворення використовується Integer.parseInt(value, 16).

Приклади:

- CAFE -> 51966
- 10 -> 16
- 7f -> 127

Якщо рядок має неправильний формат або число не вміщується в int, виникає NumberFormatException. Для null виникає NullPointerException. У задачі число обмежується діапазоном знакового типу int.

## Завдання 10 — великі літери лише для слів

Метод uppercaseWords проходить рядок зліва направо. Послідовність ASCII-літер та цифр розглядається як один токен. Якщо в токені немає цифр, він переводиться у верхній регістр; токени з цифрами, наприклад koala757677, залишаються без змін. Пробіли та розділові знаки зберігаються.

Для речення з умови результат:

THE USER WITH THE NICKNAME koala757677 THIS MONTH WROTE 3 TIMES MORE COMMENTS THAN THE USER WITH THE NICKNAME croco181dile920 4 MONTHS AGO

Порожній рядок повертається без змін. Для null метод кидає NullPointerException.

## Контрольні питання

### 1. Що таке immutable-об’єкт? Чому String незмінний і чому клас String оголошений final?

Immutable-об’єкт після створення не змінює свого стану. Будь-яка операція, що начебто змінює рядок, створює новий об’єкт String.

Незмінність String спрощує потокобезпечне спільне використання, дозволяє безпечно кешувати хеш-код і робить рядки надійними ключами в колекціях. Вона також важлива для безпеки, оскільки рядки часто містять імена класів, шляхи та інші параметри.

Клас String оголошений final, щоб його не можна було успадкувати й перевизначити поведінку методів так, щоб порушити ці властивості.

### 2. Що таке регулярні вирази? Наведіть приклади.

Регулярний вираз — шаблон для пошуку, перевірки або заміни тексту.

Приклади:

- \d+ — одна або більше цифр.
- [A-Za-z]+ — одна або більше латинських літер.
- ^[A-Za-z0-9]+$ — рядок лише з латинських літер і цифр.

У Java шаблон можна застосувати методами Pattern і Matcher або методом String.matches.

### 3. У чому різниця між оператором == та методом equals()?

Для примітивних типів == порівнює значення. Для об’єктів == перевіряє, чи обидва посилання вказують на той самий об’єкт. Метод equals() порівнює зміст відповідно до його реалізації. У String метод equals() порівнює послідовності символів.

### 4. Для чого потрібні StringBuilder та StringBuffer?

Обидва класи створюють змінювані послідовності символів і дають змогу ефективно будувати рядки багатьма операціями додавання чи заміни. StringBuilder не синхронізований і зазвичай швидший у звичайному однопотоковому коді. StringBuffer синхронізований для окремих операцій і призначений для випадків, коли один буфер спільно змінюють кілька потоків.

### 5. Як прибрати пробіли на початку та в кінці String?

Метод trim() повертає новий рядок без початкових і кінцевих символів з кодом не більшим за U+0020. У сучасній Java метод strip() прибирає пробільні символи за правилами Character.isWhitespace. Обидва методи не змінюють початковий String.

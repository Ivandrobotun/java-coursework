# Лабораторна робота № 4 — масиви

**Варіант:** 4  
**Завдання:** № 4, 34, 64  
**Мова:** Java

У розв’язаннях використані обидва обов’язкові види циклів: for-each у завданні 4, звичайний for у завданнях 34 і 64.

## Завдання 4 — кількість від’ємних елементів

Метод проходить масив циклом for-each і збільшує лічильник, коли елемент менший за нуль.

Приклад для масиву [4, -2, 0, -7, 5]: **2**.

Порожній масив дає результат 0. Для null метод кидає NullPointerException.

## Завдання 34 — індекс елемента з найбільшим модулем

Метод знаходить індекс елемента, модуль якого найбільший. Якщо найбільший модуль мають кілька елементів, повертається індекс першого. Індекс у Java починається з 0; у виводі програма також показує порядкову позицію, яка починається з 1.

Для правильного порівняння з Integer.MIN_VALUE модуль обчислюється після перетворення int на long.

Приклад для масиву [3, -10, 6, 5]: індекс **1**, позиція **2**, значення **-10**.

Порожній масив спричиняє IllegalArgumentException, а null — NullPointerException.

## Завдання 64 — перетворення масиву

Створюється новий масив тієї самої довжини. Кожний елемент перетворюється за правилом:

- від’ємні числа множаться на -1;
- додатні числа зменшуються на 3;
- нулі замінюються на -2.

Для масиву [-5, 0, 4, -3] результат: **[5, -2, 1, 3]**.

Значення Integer.MIN_VALUE не можна змінити на протилежне в типі int, тому метод повідомляє про нього через IllegalArgumentException замість переповнення.

## Контрольні питання

### 1. Чим змінна відрізняється від масиву?

Змінна зберігає одне значення певного типу. Масив зберігає фіксовану кількість значень одного типу, доступних за індексами.

### 2. Що таке стек? Що таке купа? Яка між ними різниця?

Стек зберігає кадри викликів методів і локальні дані; він працює за принципом «останнім прийшов — першим вийшов». Купа призначена для об’єктів і масивів, які створюються під час роботи програми; пам’ять у ній автоматично звільняє збирач сміття, коли об’єкти більше недосяжні.

### 3. Чи може змінна бути розташована у стеку? Безпосередньо у купі? В об’єкті у купі? Чи може масив бути розташований у стеку, безпосередньо у купі, в об’єкті у купі?

Локальна змінна зберігається у кадрі методу (концептуально — у стеку). Поле об’єкта зберігається разом з об’єктом у купі. Сам масив у Java є об’єктом у купі; локальна змінна або поле може зберігати посилання на нього.

### 4. Чим посилання на масив відрізняється від масиву? Де може зберігатися посилання?

Масив — об’єкт із даними та довжиною, а посилання — значення, через яке програма звертається до цього об’єкта. Локальне посилання зберігається у кадрі методу, а поле-посилання — в об’єкті у купі. Сам масив є об’єктом у купі.

### 5. Якщо масив складається з 10 комірок, які індекси першої та останньої комірок?

Перша комірка має індекс 0, остання — 9. Загальна довжина доступна через array.length.

### 6. Що буде, якщо звернутися до неіснуючої комірки масиву?

Java викине ArrayIndexOutOfBoundsException, який є підкласом IndexOutOfBoundsException.

### 7. Якими значеннями ініціалізуються комірки нового масиву без явної ініціалізації?

Елементи числових типів отримують 0 (для float і double — відповідні нульові значення), boolean — false, char — символ з кодом 0, посилальні типи — null. Довільні старі значення пам’яті в Java не з’являються.

### 8. Як визначити номери першої та останньої комірки, маючи посилання на масив?

Перший індекс — 0, останній — array.length - 1. Якщо посилання дорівнює null, звернення до length спричинить NullPointerException.

### 9. Як змінити розмір масиву?

Розмір створеного масиву змінити не можна. Потрібно створити новий масив потрібної довжини та скопіювати дані, наприклад за допомогою Arrays.copyOf або System.arraycopy.

### 10. Що відбувається з масивом при копіюванні посилання на нього?

Копіюється лише посилання, а не елементи. Обидві змінні посилаються на той самий масив, тому зміни його елементів видимі через обидва посилання.

### 11. Що відбувається з масивом при втраті посилання на нього?

Якщо на масив більше немає доступних посилань, він стає придатним до збирання сміття. Пам’ять звільнить збирач сміття, коли це буде потрібно.

### 12. Чим відрізняються for та for-each для роботи з масивами?

for дає змогу напряму використовувати індекс, змінювати порядок обходу та оновлювати елементи масиву за індексом. for-each коротший і зручний для послідовного читання всіх елементів, але не надає індексу. Присвоєння змінній циклу for-each не замінює елемент у масиві.

### 13. Чи можна у double[] записати int? Чи можна у int[] записати double?

У double[] можна записати int, бо перетворення int у double виконується автоматично. У int[] не можна напряму записати double; потрібне явне перетворення до int, яке може відкинути дробову частину.
